**BitTern** aims to provide low-cost, high-accuracy post-training ternary quantization tools, as well as 1.58-bit models across diverse architectures, model scales, and reasoning tasks, in PyTorch. Its goal is to lower the barrier to entry for developing 1.58-bit models, enabling broader community participation and allowing everyone can contribute and benefit from shared tools and models.
